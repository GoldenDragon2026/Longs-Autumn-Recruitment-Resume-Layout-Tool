# 龙氏秋招简历编写布局工具

> 一个**零依赖、单文件**的离线简历编辑器：四套 A4 版式所见即所得排版，自由拖拽 + 批量操作 + 统一撤销，一键导出纯净 PDF。断网双击即可使用，数据只存在你自己电脑上。

![首页四模板总览](screenshots/overview-all.png)

## 为什么做这个

秋招投不同岗位需要多套侧重点完全不同的简历。传统 Word 工作流的痛点：

| 痛点 | Word 工作流 | 本工具 |
| --- | --- | --- |
| 多版本维护 | 多个 docx 文件，版本混乱 | 四套模板同屏切换，一键对比 |
| 版式微调 | 鼠标拖文本框，牵一发动全身 | 板块级拖拽/框选/批量移动，像素级微调 |
| 误操作回滚 | Ctrl+Z 只回退文字，排版错误难还原 | 文字 + 排版 + 批量操作统一历史，120 步全可撤 |
| 导出乱版 | 另存 PDF 格式漂移 | Ctrl+P 打印导出，自动净化所有编辑器痕迹 |
| 隐私顾虑 | 在线简历网站要注册上传 | 零网络请求，内容只存本地 localStorage |

**一句话定位**：让求职者离线完成所见即所得的简历排版并导出纯净 PDF，定制一份简历从 30 分钟降到 5 分钟。

## 功能亮点

| 功能 | 说明 |
| --- | --- |
| 📄 四套 A4 模板 | 橙色经典 / 白色学术 / Agent 开发（emoji 表头版式）/ 红色横幅版，单页或四页连排切换 |
| ✏️ 所见即所得编辑 | 双击进入自由排版画布，流式文档自动转换为可拖拽板块 |
| 🖱️ 板块级交互 | 拖动（2px 判定阈值）、框选批量、Ctrl+D 整组复制、方向键 1px/10px 微调 |
| 🕐 统一撤销历史 | 120 步快照式历史，文字、排版、批量操作同一条 Ctrl+Z |
| 💾 自动保存 | 停止输入 700ms 后落盘 localStorage，刷新不丢，零上报 |
| 🖨️ 纯净导出 | Ctrl+P 导出 PDF（@media print 自动隐藏工具栏/网格/边框），或下载独立 HTML 副本分发 |
| 🔌 零依赖 | 单 HTML 文件 ≈55KB，无 CDN / 字体 / 框架 / 网络请求，断网 100% 可用 |

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 表现 | 原生 HTML / CSS | A4 版式用 pt 单位 1:1 还原打印尺寸；@media print 导出净化 |
| 交互 | 原生 JavaScript + Pointer Events | 指针交互状态机（按下待定 → 拖动/框选/编辑分流） |
| 数据 | localStorage + innerHTML 快照 | 四键独立保存 `{r1,r2,r3,r4}`；快照式统一撤销 |
| 构建 | 无 | 无打包、无框架、无依赖，文件即应用 |

## 可深挖的技术点

1. **流式 → 画布自动转换算法**：进入编辑时把语义化 HTML 流式文档一次性转换为绝对定位板块画布（每个板块测量原位置落点），退出时反向还原——同一份数据两种形态，避免了维护两套 DOM。
2. **快照式统一撤销（而非命令模式）**：DOM 编辑命令（execCommand 产物）难以完备枚举，改用 `innerHTML` 快照 + 400ms 打字合并防抖，实现文字/排版/批量操作 100% 覆盖的 120 步历史，实现简单且绝对正确。
3. **指针交互状态机**：pointerdown 后进入"待定"态，按位移（2px/3px 阈值）与落点（板块边框 6px 热区）分流为拖动 / 框选 / 文字编辑三种模式，杜绝手抖误判与事件竞争。
4. **序列化清洁**：自动保存与导出共享一套"净化"逻辑——克隆 DOM → 剥离编辑态属性/类 → 序列化，保证落盘数据与导出产物都无编辑器痕迹。
5. **零依赖导出链路**：不引入 html2pdf 之类的库，直接利用浏览器打印管线（@media print 强制净化）导出 PDF，体积与渲染一致性都优于 canvas 截图方案。
